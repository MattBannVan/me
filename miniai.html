MiniAI Visualizer

A desktop app that visualises token-by-token language model math — with a live softmax table, temperature slider, and a REINFORCE feedback loop.

What it does

MiniAI Visualizer runs a tiny language model step-by-step and shows you every piece of the math as it happens: the hidden context vector h, the raw logits z = W·h + b, temperature scaling z / T, and the final softmax distribution over the vocabulary.

After each token is generated you can press 👍 or 👎 to apply a REINFORCE-style weight update — the model's weights are adjusted immediately and auto-saved to disk.

The math, step by step

Stage Formula Shown in UI
Context h′ = tanh(U·h + Vin·E[token] + bh) Math log — h, ‖h‖
Logits z = W·h + b, W ∈ ℝV×32 Table — "logit z"
Temperature z̃ = z / T, T ∈ [0.1, 2.0] Table — "z/T" (live)
Softmax pi = ez̃i / Σ ez̃j Table — "p" + bars
Sampling token ~ Categorical(p) Math log — "sampled →"
RL update ∂(−J)/∂bj = −r·(𝟙[j=t] − pj) Math log — RL section

How to use it

  • 1First launch — the model quick-pretrains on a built-in corpus (a few seconds), then saves weights locally. Later launches load those weights, including every feedback update you've applied.
  • 2Temperature slider (0.1 – 2.0) — drag it and watch the top-10 distribution table update live. Low T sharpens softmax toward the argmax; high T flattens it toward uniform. No token is generated until you press the button.
  • 3Generate Next Token — samples one token from softmax(z/T) and appends a full breakdown to the math log.
  • 4Feedback (RL loop) — press 👍 +1.0 or 👎 −0.5 after a token. The engine runs one REINFORCE step on the output head, shows the weight delta and probability change, and auto-saves to disk.

Setup (Windows, Python 3.10 – 3.12)

Requires PyTorch ≥ 2.7 built against CUDA 12.8 for RTX 5060 (Blackwell) support. Older wheels do not contain Blackwell kernels. Install in this order:

:: 1) create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate

:: 2) CUDA-enabled PyTorch (cu128 wheels bundle the CUDA runtime)
pip install "torch>=2.7" --index-url https://download.pytorch.org/whl/cu128

:: 3) GUI + storage libraries
pip install customtkinter safetensors numpy

:: 4) run the app
python app.py

If CUDA is unavailable the app transparently falls back to CPU — the device in use is shown in the top-left of the window.
